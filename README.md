# Kephalonian Demigod

A **Rainmeter** desktop skin inspired by **Assassin's Creed Odyssey**, recreating several elements of the game's HUD while turning them into useful desktop widgets.

The goal of this project was to blend desktop functionality with the visual style of Assassin's Creed Odyssey without sacrificing usability.

> Originally released on DeviantArt in 2022.

## Features

### Immersive interface

- Animated greeting inspired by the game
- Decorative compass
- Hover quotes displayed similarly to in-game subtitles (spoiler-free)

### System monitoring

#### Player Level

The **CPU meter** is represented as the player's level.

- Displays the available CPU percentage
- Styled after the game's progression interface

#### Bounty Bar

The **RAM meter** is represented as the bounty meter.

- Filled bar indicating current RAM usage
- Visual markers at:
  - 20%
  - 40%
  - 60%
  - 80%
  - 95%

### Ability Bar launcher

The launcher recreates the game's ability bar and provides quick access to frequently used applications.

#### Left side

- Control Panel
- Spotify
- Steam
- Discord

#### Right side

- File Explorer
- Google Chrome
- Google Calendar
- Gmail

## Installation

1. Install the latest version of **Rainmeter**.
2. Download or clone this repository.
3. Copy the skin folder into:

```
Documents\Rainmeter\Skins\
```

4. Refresh Rainmeter and load the skin.

---

## Customization

### Application paths

Applications are configured using their default installation paths.

If an application is installed elsewhere:

- edit the corresponding `.ini` file
- modify the `LeftMouseDownAction`
- or point it to your own shortcut

Configuration files contain comments to help with customization.
